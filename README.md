## 🚀 Key Projects

### 🔌 Industrial IoT Gateway
Custom Python gateway connecting PLCs (Siemens S7, OPC-UA, Modbus) to cloud/on-premise platforms via MQTT. Features: offline SQLite buffering, delta config deployment, RPC command reliability, automatic failover.

### 🖥️ On-Premise SCADA Platform
Full-stack IoT platform deployable on customer hardware. Real-time dashboards, alarm management with notifications, zero-export control, user/role management. Built as an alternative to WinCC and InScada for mid-scale industrial facilities.

### ⚡ Zero Export Controller
Automated grid export control system — reads inverter/meter data via Modbus, dynamically curtails output to stay within grid limits. Deployed in active solar facilities.
